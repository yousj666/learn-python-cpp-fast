# 极速学 Python 与 C++ / Learn Python & C++ Fast

一套为零基础学习者准备的双语开源教程：**Python 线**和 **C++ 线**各 8 课，
每课都有能直接运行的完整代码、常见坑提醒和练习题。
不堆概念，只讲能马上用上的东西——学完每一课，你都能写出一个真能跑的小程序。

> 在线阅读（排版版）：https://yousj.cc/learn/

## 为什么是这两门语言

- **Python**：上手最快的语言。自动化脚本、数据处理、AI 工具、后端开发都用它，
  语法接近自然语言，适合第一门语言。
- **C++**：最贴近计算机底层的通用语言之一。游戏引擎、操作系统、高性能服务、
  竞赛算法都离不开它，学完它再看任何语言都会轻松很多。

两条线可以只学一条，也可以对照着学：很多概念（变量、循环、函数、类）
在两门语言里是相通的，对照学反而记得更牢。

## 如何使用

1. **按顺序学**：每课都建立在上一课的基础上，不要跳。
2. **代码必须亲手敲**：把每课的代码复制到文件里运行，再改几个数字看看结果变化。
   只看不敲，等于没学。
3. **先做练习再看答案**：每课末尾有 2–3 道练习，答案折叠在课文最后。
4. **卡住超过 20 分钟就先跳过**：标记下来，学完后面回头再看，往往就通了。

### 运行代码的方法

Python（任意一课的代码存为 `demo.py` 后）：

```bash
python3 demo.py
```

C++（任意一课的代码存为 `demo.cpp` 后）：

```bash
g++ -std=c++17 -Wall -o demo demo.cpp
./demo
```

## 建议节奏

- 每天 1 课、约 1 小时：16 天学完两条线。
- 只赶一门语言：8 天，每天 1 课。
- 学完之后：挑第 08 课的项目自己重写一遍（不看原文），能独立写出来才算过关。
