# Python 第 06 课：文件与异常

## 本课目标

- 用 `open()` 读写文本文件，让数据在程序关闭后还能留下来
- 理解 `with` 语句为什么是读写文件的标准写法
- 用 `try / except` 处理异常，让程序遇到错误也不崩溃

## 1. 为什么需要文件

到目前为止，程序里的数据都存在内存里，程序一关就全没了。
把数据写进文件，数据就能长期保存——存档、日志、配置都靠它。

## 2. 写文件

```python
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行：今天开始学文件操作\n")
    f.write("第二行：数据不会丢了\n")

print("写入完成")
```

运行后，当前目录会出现 `note.txt`，内容就是这两行。

拆开看：

- `open(文件名, 模式, encoding="utf-8")`：`"w"` 是写入模式（文件不存在就新建，
  存在就清空重写）；中文文件务必写上 `encoding="utf-8"`，否则可能乱码
- `with ... as f`：把打开的文件叫做 `f`，`with` 块结束时**自动关闭文件**，
  这是标准写法，不用再操心 `close()`
- `\n` 是换行符，不加的话所有内容会挤在一行

追加而不是覆盖，用 `"a"` 模式：

```python
with open("note.txt", "a", encoding="utf-8") as f:
    f.write("第三行：这是追加的\n")
```

## 3. 读文件

```python
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

逐行读取更常用，适合处理大文件：

```python
with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print("读到一行：", line.strip())   # strip() 去掉行尾换行符
```

## 4. 一个完整的例子：记分板

把写入和读取连起来，做一个能保存成绩的小程序：

```python
# 保存三位同学的成绩到文件
records = [
    ("小明", 95),
    ("小红", 88),
    ("小刚", 76),
]

with open("scores.txt", "w", encoding="utf-8") as f:
    for name, score in records:
        f.write(f"{name},{score}\n")

# 重新读回来并计算平均分
total = 0
count = 0
with open("scores.txt", "r", encoding="utf-8") as f:
    for line in f:
        name, score = line.strip().split(",")
        total = total + int(score)
        count = count + 1

print("平均分", total / count)
```

注意：从文件读回来的永远是字符串，`score` 要用 `int()` 转回数字才能算。

## 5. 异常：程序出错时别崩溃

打开一个不存在的文件会发生什么？程序会抛出异常并终止。
用 `try / except` 可以「接住」异常，给出友好的处理：

```python
try:
    with open("不存在的文件.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("文件不存在，请先创建它")
```

结构是：把可能出错的代码放进 `try`，出错时跳到对应的 `except` 执行，
程序不会崩溃，后面的代码照常运行。

最常见的应用场景是处理用户的错误输入：

```python
text = "abc"     # 假设这是用户输入的内容，故意写错

try:
    number = int(text)
    print("转换成功：", number)
except ValueError:
    print("输入的不是数字，无法转换")
```

还可以兜底接住所有异常（但优先写明确的异常类型，方便定位问题）：

```python
try:
    result = 10 / 0
    print(result)
except ZeroDivisionError:
    print("除数不能为 0")
```

## 常见坑

1. **忘了写 encoding**：读写中文文件不写 `encoding="utf-8"`，
   在 Windows 上很容易乱码或报错。
2. **`"w"` 模式会清空原文件**：只是想在末尾加内容时用 `"a"`，
   用错模式数据就没了。
3. **except 写得太宽**：`except:` 把所有错误都吞掉，真正的 bug 会被藏起来，
   出问题时无从查起。能写具体类型就写具体类型。
4. **读回来的数字是字符串**：文件里没有「数字」这个概念，全是文本，
   用之前记得 `int()` / `float()` 转换。

def safe_divide(a, b):
