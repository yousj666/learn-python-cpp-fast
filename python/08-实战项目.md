# Python 第 08 课：实战项目——命令行待办清单

## 本课目标

把前七课的知识全部用上，做一个真能日常使用的工具：
**命令行待办清单**。功能包括：

- 添加待办事项
- 查看所有事项（区分已完成 / 未完成）
- 标记完成、删除事项
- 数据保存在文件里，关掉程序不丢失

用到的知识：第 02 课的变量、第 03 课的条件循环、第 04 课的函数、
第 05 课的列表与字典、第 06 课的文件与异常。

## 1. 设计思路

- 每条待办是一个字典：`{"title": "买牛奶", "done": False}`
- 所有待办是一个列表，整个列表用 JSON 格式存进 `tasks.json`
  （JSON 是最常用的数据交换格式，Python 用 `json` 模块读写）
- 程序通过命令行参数决定做什么：
  `python todo.py add 买牛奶`、`python todo.py list` 等

## 2. 完整代码

把下面代码完整存为 `todo.py`：

```python
import json
import sys

DATA_FILE = "tasks.json"


def load_tasks():
    """读取已保存的待办列表，文件不存在或损坏时返回空列表"""
    try:
        with open(DATA_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("数据文件损坏，已按空列表处理")
        return []


def save_tasks(tasks):
    """把待办列表保存到文件"""
    with open(DATA_FILE, "w", encoding="utf-8") as f:
        json.dump(tasks, f, ensure_ascii=False, indent=2)


def cmd_add(tasks, title):
    tasks.append({"title": title, "done": False})
    print(f"已添加：{title}")


def cmd_list(tasks):
    if not tasks:
        print("暂无待办事项")
        return
    for i, task in enumerate(tasks, start=1):
        mark = "✓" if task["done"] else " "
        print(f"{i}. [{mark}] {task['title']}")


def cmd_done(tasks, index):
    task = tasks[index - 1]
    task["done"] = True
    print(f"已完成：{task['title']}")


def cmd_remove(tasks, index):
    task = tasks.pop(index - 1)
    print(f"已删除：{task['title']}")


def main():
    args = sys.argv[1:]
    if not args:
        print("用法：")
        print("  python todo.py add <事项>    添加待办")
        print("  python todo.py list          查看全部")
        print("  python todo.py done <序号>   标记完成")
        print("  python todo.py remove <序号> 删除事项")
        return

    tasks = load_tasks()
    command = args[0]

    if command == "add" and len(args) >= 2:
        cmd_add(tasks, " ".join(args[1:]))
        save_tasks(tasks)
    elif command == "list":
        cmd_list(tasks)
    elif command in ("done", "remove") and len(args) >= 2:
        try:
            index = int(args[1])
            if not 1 <= index <= len(tasks):
                print("序号超出范围")
                return
            if command == "done":
                cmd_done(tasks, index)
            else:
                cmd_remove(tasks, index)
            save_tasks(tasks)
        except ValueError:
            print("序号必须是数字")
    else:
        print("未知命令，先运行 python todo.py 查看用法")


if __name__ == "__main__":
    main()
```

## 3. 运行演示

在 `todo.py` 所在目录打开终端，依次执行：

```bash
python3 todo.py add 买牛奶
python3 todo.py add 学完 Python 第 08 课
python3 todo.py add 给花浇水
python3 todo.py list
python3 todo.py done 2
python3 todo.py list
python3 todo.py remove 1
python3 todo.py list
```

`list` 第一次的输出是：

```
1. [ ] 买牛奶
2. [ ] 学完 Python 第 08 课
3. [ ] 给花浇水
```

`done 2` 之后再 `list`，第二项会变成 `[✓]`。
关掉终端再打开运行 `python3 todo.py list`，数据还在——
因为它们躺在同目录的 `tasks.json` 里。

## 4. 代码里值得注意的设计

1. **`load_tasks` 的异常处理**：第一次运行时文件还不存在，
   `FileNotFoundError` 时返回空列表，程序照常工作（第 06 课）。
2. **序号从 1 开始**：`enumerate(tasks, start=1)` 给人看的序号是 1、2、3，
   操作时再用 `index - 1` 换回列表下标（第 05 课）。
3. **改完就保存**：只有 add / done / remove 成功后才调用 `save_tasks`，
   list 只是查看，不写文件。
4. **`if __name__ == "__main__":`**：意思是「这个文件被直接运行时才执行
   main()」，是 Python 程序的标准入口写法，以后每个正式脚本都可以这么写。

## 常见坑

1. **在别的目录运行**：`tasks.json` 生成在「运行命令时所在目录」，
   换个目录运行就会新建一份空数据。演示时先 `cd` 到 `todo.py` 所在目录。
2. **add 后面不加事项**：`python todo.py add` 会走进「未知命令」提示，
   这是代码里特意做的参数检查。
3. **手动改坏 tasks.json**：JSON 格式很严格，少个引号都会触发
   `JSONDecodeError`——程序已经处理了这种情况，但数据会按空列表对待，
   别手贱。

## 练习

1. 给工具加一个 `clear` 命令：删除所有已完成的事项
   （提示：用列表推导式保留 `done` 为 False 的项，或逐个筛选）。
2. 给每条待办加上添加日期：`add` 时把当天日期一起存进字典并在
   `list` 时显示（提示：`from datetime import date`，
   `str(date.today())` 就是今天日期）。
3. 挑战：加一个 `search 关键词` 命令，只列出标题里包含关键词的事项。

    elif command == "clear":

from datetime import date

def cmd_add(tasks, title):

`cmd_list` 的打印改为 `print(f"{i}. [{mark}] {task['title']}（{task['date']}）")`。

def cmd_search(tasks, keyword):
    found = False
    for i, task in enumerate(tasks, start=1):
        if keyword in task["title"]:
            mark = "✓" if task["done"] else " "
            print(f"{i}. [{mark}] {task['title']}")
            found = True
    if not found:
        print("没有匹配的事项")
