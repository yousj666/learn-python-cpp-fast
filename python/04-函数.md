# Python 第 04 课：函数

## 本课目标

- 理解为什么要把代码打包成函数
- 学会定义函数、传参数、用 `return` 返回结果
- 掌握默认参数和作用域的概念

## 1. 为什么需要函数

假设程序里有三处都要算「长方形面积」，与其把 `长 * 宽` 抄三遍，
不如打包成一个函数，到处调用：

```python
def rectangle_area(width, height):
    return width * height

print(rectangle_area(3, 4))    # 12
print(rectangle_area(5, 6))    # 30
print(rectangle_area(10, 2))   # 20
```

拆开看：

- `def` 是定义函数的关键字，后面跟函数名和括号
- 括号里的 `width, height` 是**参数**：调用时传进来的数据
- `return` 把计算结果交还给调用处；没有 `return` 的函数返回 `None`

函数定义只是「登记菜谱」，不会自动执行；**调用**（写函数名加括号）才真正做菜。

## 2. 没有返回值的函数

有些函数只负责做事（比如打印），不需要交回结果：

```python
def say_hello(name):
    print("你好，", name, "！欢迎学习 Python")

say_hello("小明")
say_hello("小红")
```

## 3. 默认参数

给参数设定默认值，调用时可以省略它：

```python
def power(base, exp=2):
    return base ** exp

print(power(5))       # 25，没传 exp，用默认值 2（平方）
print(power(2, 10))   # 1024，传了 exp 就用传入的
```

带默认值的参数必须放在没有默认值的参数**后面**。

## 4. 多个返回值

Python 的函数可以一次返回多个值，本质是打包成一个元组：

```python
def min_max(numbers):
    return min(numbers), max(numbers)

small, big = min_max([3, 9, 1, 7, 5])
print("最小", small, "最大", big)
```

## 5. 作用域：变量的活动范围

函数内部定义的变量叫**局部变量**，只在函数里有效；
函数外定义的叫**全局变量**：

```python
x = 10    # 全局变量

def show():
    x = 99          # 这是函数自己的局部变量，不影响外面的 x
    print("函数里", x)

show()
print("函数外", x)
```

输出：

```
函数里 99
函数外 10
```

原则：函数尽量只通过参数接收数据、通过 `return` 交出结果，
少直接改全局变量，程序会好懂得多。

## 6. 把猜数字游戏重构成函数

函数真正的威力是**组织程序结构**。上一课的猜数字游戏可以拆成两块：

```python
import random

def check(guess, answer):
    if guess > answer:
        return "太大了"
    elif guess < answer:
        return "太小了"
    else:
        return "对了"

def play():
    answer = random.randint(1, 50)
    while True:
        guess = int(input("猜一个 1~50 的数字："))
        result = check(guess, answer)
        print(result)
        if result == "对了":
            break

play()
```

主流程 `play()` 只管「怎么玩」，判断细节交给 `check()`——
以后想改提示语，只动 `check` 一处就行。这就是函数式拆分的价值。

## 常见坑

1. **定义了却没调用**：写完 `def` 后忘了在下面调用函数名，程序运行后毫无反应。
2. **把 print 当 return 用**：函数里 `print(结果)` 只是显示给人看，
   调用处拿不到这个值；要让别处能用，必须 `return`。
3. **`return` 后面的代码不执行**：`return` 一旦执行函数立刻结束，
   写在它后面的行永远不会跑。
4. **参数顺序搞反**：`rectangle_area(3, 4)` 中 3 是宽、4 是高，
   调用时按定义时的顺序传。
