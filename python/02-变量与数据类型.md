# Python 第 02 课：变量与数据类型

## 本课目标

- 理解变量是什么、怎么命名
- 掌握四种基本数据类型：int、float、str、bool
- 学会用 `type()` 查看类型、用 `int()` / `str()` 等做类型转换

## 1. 变量：给数据起个名字

变量就像一个贴了标签的盒子，把数据装进去，之后用标签就能取用：

```python
score = 95
name = "小红"
price = 19.9

print(score)
print(name)
print(price)
```

变量可以随时改装别的东西：

```python
mood = "开心"
print(mood)

mood = "非常开心"   # 重新赋值，旧值被覆盖
print(mood)
```

**命名规则**：

- 只能用字母、数字、下划线，且不能以数字开头（`2name` 是错的）
- 区分大小写：`Age` 和 `age` 是两个不同的变量
- 起有意义的名字：`student_count` 比 `sc` 好懂得多
- Python 习惯用小写加下划线，如 `total_price`，这叫 snake_case

## 2. 四种基本数据类型

```python
count = 42          # int：整数
pi = 3.14           # float：小数（浮点数）
message = "你好"     # str：字符串（文本）
is_open = True      # bool：布尔值，只有 True / False

print(type(count))
print(type(pi))
print(type(message))
print(type(is_open))
```

输出：

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

### 整数和小数的运算

```python
a = 10
b = 3

print(a + b)    # 13，加法
print(a - b)    # 7，减法
print(a * b)    # 30，乘法
print(a / b)    # 3.3333333333333335，除法（结果总是小数）
print(a // b)   # 3，整除（只取整数部分）
print(a % b)    # 1，取余数
print(a ** b)   # 1000，幂运算：10 的 3 次方
```

`%` 取余非常常用，比如判断奇偶：`n % 2 == 0` 就是「n 是偶数」。

### 字符串的基本操作

```python
first = "Py"
second = "thon"

print(first + second)     # Python，字符串拼接
print("ha" * 3)           # hahaha，重复
print(len("你好，世界"))    # 6，长度（每个汉字算 1）
```

字符串还能用下标取出单个字符，下标从 **0** 开始数：

```python
word = "Python"

print(word[0])    # P，第一个字符
print(word[1])    # y
print(word[-1])   # n，最后一个字符（负数从末尾数）
print(word[0:3])  # Pyt，切片：取下标 0、1、2，不含 3
```

## 3. 类型转换

从键盘或文件读进来的数据常常是字符串，想拿来算数必须先转换：

```python
age_text = "18"          # 这是字符串，不是数字
age = int(age_text)      # 转成整数 18

print(age + 1)           # 19，可以算了
print(float("3.5"))      # 3.5，字符串转小数
print(str(100))          # "100"，数字转字符串
print(int(9.8))          # 9，小数转整数是直接截断，不是四舍五入
```

拼字符串时数字必须先转成字符串，否则报错：

```python
score = 95
print("我的分数是：" + str(score))
```

## 4. 布尔值与比较

比较运算的结果就是布尔值，它是下一课「条件判断」的地基：

```python
print(10 > 3)     # True
print(10 < 3)     # False
print(5 == 5)     # True，两个等号才是「比较是否相等」
print(5 != 5)     # False，!= 表示「不等于」
print(7 >= 7)     # True，大于等于
```

## 常见坑

1. **`=` 和 `==` 混淆**：`=` 是赋值（把右边给左边），`==` 才是比较。
2. **字符串数字直接相加**：`"18" + "1"` 得到的是 `"181"`（拼接），
   不是 `19`。先用 `int()` 转换。
3. **除法结果是小数**：`10 / 2` 得到 `5.0` 而不是 `5`，需要整数用 `//`。
4. **浮点数不精确**：`0.1 + 0.2` 会得到 `0.30000000000000004`，
   这是所有编程语言的通病，涉及钱时要用专门的 Decimal 类型（进阶内容）。
