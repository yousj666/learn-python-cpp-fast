# Python 第 01 课：环境与第一个程序

## 本课目标

- 在电脑上装好 Python，并确认能运行
- 写出并运行你的第一个 Python 程序
- 学会用 `print()` 输出内容、用 `#` 写注释

## 1. 安装 Python

去 [python.org/downloads](https://www.python.org/downloads/) 下载最新版安装包：

- **Windows**：安装时务必勾选 **Add Python to PATH**，不勾后面会报错。
- **macOS**：装好后在终端里用 `python3` 命令。
- **Linux**：多数发行版自带 Python 3，终端输入 `python3 --version` 确认。

装完后打开终端（命令行），输入：

```bash
python3 --version
```

能看到类似 `Python 3.12.x` 的输出，就说明装好了。

## 2. 第一个程序

新建一个文本文件，命名为 `hello.py`，写入下面这行，保存：

```python
print("你好，世界！")
```

回到终端，进入文件所在目录，运行：

```bash
python3 hello.py
```

终端会输出：

```
你好，世界！
```

恭喜，你已经是一个能让计算机听话的人了。

## 3. print() 能做什么

`print()` 是 Python 最常用的输出函数。它能输出文字、数字，也能一次输出多项内容：

```python
print("我正在学 Python")
print(2026)
print("今年是", 2026, "年")
print(3 + 4)
```

运行结果：

```
我正在学 Python
2026
今年是 2026 年
7
```

注意第三行：多个内容用逗号隔开，输出时会自动用空格连接。
第四行更重要：`3 + 4` 没有引号，Python 会先算出结果 `7` 再输出；
而 `"3 + 4"` 带引号的话，输出的就是这四个字符本身。

## 4. 注释：写给人看的说明

以 `#` 开头的内容是注释，Python 运行时会完全跳过它：

```python
# 这是一个猜数字小游戏的开头（本课先只打印标题）
print("=== 猜数字游戏 ===")   # 行尾也可以写注释

# 下面这行被注释掉了，不会执行
# print("这行不会出现")
```

注释的用处：给未来的自己（和别人）解释「这段代码为什么这么写」。
写代码时多写注释，是性价比最高的习惯之一。

## 5. 让程序多说几句

把前面学的拼起来，写一个自我介绍程序：

```python
name = "小明"          # 先把名字存进变量（下一课细讲）
age = 16

print("大家好，我叫", name)
print("我今年", age, "岁")
print("明年我就", age + 1, "岁了")
```

输出：

```
大家好，我叫 小明
我今年 16 岁
明年我就 17 岁了
```

`name = "小明"` 的意思是把 `"小明"` 存到名为 `name` 的变量里，
之后写 `name` 就等于用这个值。变量是下一课的主题，这里先有个印象即可。

## 常见坑

1. **用了中文标点**：代码里的引号、括号、逗号必须是英文半角符号。
   写成 `print（"你好"）` 会直接报 `SyntaxError`。
2. **文件名别叫 `python.py`**：文件名和 Python 自己的模块重名会引发奇怪的错误，
   练习文件用 `lesson1.py`、`demo.py` 这类名字最安全。
3. **Windows 上命令是 `python` 或 `py`**：如果 `python3` 提示找不到，
   试试 `python --version` 或 `py --version`。
4. **缩进不要乱动**：Python 靠缩进划分代码块，本课的代码都是顶格写的，
   不要随手在行首加空格。

## 练习
