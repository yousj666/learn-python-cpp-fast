# Python 第 05 课：数据结构

## 本课目标

- 用 list（列表）保存一组有序数据
- 用 dict（字典）保存键值对
- 用 set（集合）去重和判断成员
- 掌握字符串的常用处理方法

单个变量只能装一个值，真实程序要处理的是「一堆数据」：
一个班的学生、一周的气温、一本通讯录——这就是数据结构的用武之地。

## 1. list 列表：有序的队伍

```python
fruits = ["苹果", "香蕉", "橙子"]

print(fruits[0])        # 苹果，下标从 0 开始
print(fruits[-1])       # 橙子，最后一个
print(len(fruits))      # 3，元素个数

fruits.append("葡萄")    # 在末尾添加
print(fruits)           # ['苹果', '香蕉', '橙子', '葡萄']

fruits[1] = "芒果"       # 修改下标 1 的元素
print(fruits)           # ['苹果', '芒果', '橙子', '葡萄']

fruits.remove("橙子")    # 按值删除
print(fruits)           # ['苹果', '芒果', '葡萄']
```

遍历列表是最高频的操作：

```python
scores = [88, 95, 72, 100, 66]

total = 0
for s in scores:
    total = total + s

print("平均分", total / len(scores))
```

排序和常用统计：

```python
nums = [5, 2, 9, 1, 7]

nums.sort()             # 原地排序，从小到大
print(nums)             # [1, 2, 5, 7, 9]
print(max(nums))        # 9
print(min(nums))        # 1
print(sum(nums))        # 24
print(9 in nums)        # True，in 判断元素在不在列表里
```

## 2. dict 字典：带标签的储物柜

字典用「键 → 值」的方式存数据，靠名字取值，不靠下标：

```python
student = {
    "name": "小明",
    "age": 16,
    "score": 95,
}

print(student["name"])     # 小明
print(student["score"])    # 95

student["score"] = 98      # 修改已有键
student["city"] = "福州"   # 添加新键
print(student)

print(student.get("phone", "未填写"))  # 键不存在时给默认值，不报错
```

遍历字典：

```python
prices = {"苹果": 5, "香蕉": 3, "橙子": 4}

for fruit, price in prices.items():
    print(fruit, "每斤", price, "元")
```

列表和字典经常组合使用，比如通讯录就是「装着字典的列表」：

```python
contacts = [
    {"name": "小明", "phone": "13800000001"},
    {"name": "小红", "phone": "13800000002"},
]

for c in contacts:
    print(c["name"], "的电话是", c["phone"])
```

## 3. set 集合：自动去重的袋子

集合里的元素不重复、无固定顺序，适合去重和成员判断：

```python
tags = {"python", "编程", "python", "教程"}

print(tags)              # 只剩一个 'python'，自动去重了
print(len(tags))         # 3

tags.add("开源")
print("编程" in tags)     # True，成员判断
```

列表转集合再转回来，是最常用的去重手法：

```python
raw = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(raw))
print(unique)            # [1, 2, 3, 4]（顺序可能不同，集合无序）
```

## 4. 字符串处理

字符串本身就是「字符的序列」，很多列表技巧通用。常用方法：

```python
text = "  Hello, Python World  "

print(text.strip())            # 去掉两端空格
print(text.lower())            # 全小写（strip 后更明显，这里含原空格）
print("Python" in text)        # True，子串判断

words = "苹果,香蕉,橙子".split(",")   # 按逗号切开成列表
print(words)                          # ['苹果', '香蕉', '橙子']

joined = "-".join(["2026", "11", "27"])  # 把列表拼成字符串
print(joined)                            # 2026-11-27
```

f-string 是拼字符串最好用的方式，把变量直接嵌进字符串：

```python
name = "小明"
score = 95

print(f"{name} 的分数是 {score} 分")
print(f"明年分数目标：{score + 5} 分")   # 大括号里可以写表达式
```

## 常见坑

1. **字典用不存在的键取值会报错**：`student["phone"]` 在没有这个键时抛
   `KeyError`；不确定时用 `.get(键, 默认值)`。
2. **遍历时修改列表**：一边 `for` 遍历一边 `remove` 元素会漏掉元素，
   先生成新列表再替换更稳妥。
3. **`sort()` 没有返回值**：它直接改原列表，`new = nums.sort()` 里的
   `new` 会是 `None`。想要新列表用 `sorted(nums)`。
4. **集合无序**：不要指望集合保持插入顺序，需要顺序就用列表。

## 练习

1. 有一份成绩列表 `[72, 85, 90, 66, 95, 58, 88]`，统计及格（≥60）的人数，
   并输出最高分和平均分。
2. 用字典保存三门课的成绩（语文、数学、英语，自选分数），
   遍历字典打印每门课和分数，最后打印总分。
3. 把句子 `"the quick brown fox jumps over the lazy dog"` 切成单词列表，
   统计一共有几个**不重复**的单词。

```python
# 练习 1
scores = [72, 85, 90, 66, 95, 58, 88]

passed = 0
for s in scores:
    if s >= 60:
        passed = passed + 1

print("及格人数", passed)
print("最高分", max(scores))
print("平均分", sum(scores) / len(scores))
```

```python
# 练习 2
grades = {"语文": 88, "数学": 95, "英语": 92}

total = 0
for subject, score in grades.items():
    print(subject, score)
    total = total + score

print("总分", total)
```

```python
# 练习 3
sentence = "the quick brown fox jumps over the lazy dog"
words = sentence.split()
print("单词总数", len(words))
print("不重复单词数", len(set(words)))
```
