# Python 第 07 课：面向对象入门

## 本课目标

- 理解类（class）和对象（object）是什么关系
- 学会写 `__init__` 初始化方法、属性和方法
- 理解继承：子类复用父类的代码

## 1. 为什么需要类

假设要管理很多学生，每人有姓名、年龄、成绩。
用字典也能存，但数据和「对数据的操作」是分开的，程序一大就乱。
**类**就是把数据和操作打包在一起的模板：

- 类 = 图纸（比如「学生」这个概念）
- 对象 = 按图纸造出来的实物（比如学生小明、学生小红）

## 2. 定义第一个类

```python
class Student:
    def __init__(self, name, score):
        self.name = name      # 属性：这个学生自己的名字
        self.score = score    # 属性：这个学生自己的分数

    def introduce(self):
        print(f"我是 {self.name}，这次考了 {self.score} 分")

    def is_passed(self):
        return self.score >= 60


ming = Student("小明", 95)     # 按图纸造对象：调用类名就像调用函数
hong = Student("小红", 58)

ming.introduce()
hong.introduce()
print("小明及格了吗？", ming.is_passed())
print("小红及格了吗？", hong.is_passed())
```

要点：

- `class Student:` 定义类，类名习惯首字母大写
- `__init__` 是**初始化方法**，造对象时自动执行，负责把初始数据装好
- `self` 代表「对象自己」，每个方法第一个参数都是它，调用时不用手动传
- 属性写成 `self.name`，属于对象自己；每个对象的属性互不干扰

## 3. 方法可以修改对象状态

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self.balance = 0          # 余额从 0 开始

    def deposit(self, amount):
        self.balance = self.balance + amount
        print(f"存入 {amount} 元，余额 {self.balance} 元")

    def withdraw(self, amount):
        if amount > self.balance:
            print("余额不足，取款失败")
        else:
            self.balance = self.balance - amount
            print(f"取出 {amount} 元，余额 {self.balance} 元")


account = BankAccount("小明")
account.deposit(500)
account.withdraw(120)
account.withdraw(1000)
```

输出：

```
存入 500 元，余额 500 元
取出 120 元，余额 380 元
余额不足，取款失败
```

对象把「数据（余额）」和「规则（不能透支）」绑在一起——
这正是面向对象的核心价值：**谁的数据谁负责，规则写在类里，处处生效**。

## 4. 继承：站在父类的肩膀上

新类可以继承已有类的全部属性和方法，再追加自己的东西：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出了声音")


class Dog(Animal):            # Dog 继承 Animal
    def speak(self):          # 重写父类的方法
        print(f"{self.name}：汪汪！")


class Cat(Animal):
    def speak(self):
        print(f"{self.name}：喵喵~")


dog = Dog("旺财")   # __init__ 直接用父类的，不用重写
cat = Cat("咪咪")

dog.speak()
cat.speak()
```

子类和父类同名方法，以子类的为准（这叫**重写 / override**）。
同一个 `speak()` 调用，不同对象表现不同，这叫**多态**——
听起来玄乎，其实就是「同一声令下，各干各的」。

## 5. 什么时候用类，什么时候用函数

- 数据和行为绑得紧、要造很多个同类实例 → 用类（学生、账户、商品）
- 只是一个独立的计算或处理步骤 → 用函数就够了（算面积、转温度）
- 新手判断口诀：名词多半是类，动词多半是函数（方法）

## 常见坑

1. **方法忘了写 self**：`def introduce():` 少了 `self`，
   调用时报参数数量错误。每个实例方法的第一个参数都要是 `self`。
2. **属性写在 `__init__` 外面**：直接在类里写 `name = "小明"` 是全班共享的
   类属性，不是每个对象自己的。每个对象独立的属性必须写成 `self.xxx`。
3. **把类当对象用**：`Student.introduce()` 直接拿类调实例方法会报错，
   先造对象：`s = Student(...)` 再 `s.introduce()`。
4. **继承时忘了父类的 `__init__`**：子类如果重写了 `__init__`，
   记得用 `super().__init__(...)` 调用父类的初始化，否则父类属性不存在。

```python
# 练习 1
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)


r1 = Rectangle(3, 4)
print(r1.area(), r1.perimeter())
r2 = Rectangle(5, 6)
print(r2.area(), r2.perimeter())
```

```python
# 练习 2
class Book:
    def __init__(self, title, author, pages):
        self.title = title
        self.author = author
        self.pages = pages

    def describe(self):
        print(f"《{self.title}》— {self.author}，共 {self.pages} 页")

    def is_long(self):
        return self.pages > 300


book = Book("Python 编程入门", "张老师", 280)
book.describe()
print("是长篇吗？", book.is_long())
```
