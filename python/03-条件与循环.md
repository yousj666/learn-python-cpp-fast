# Python 第 03 课：条件与循环

## 本课目标

- 用 `if / elif / else` 让程序做判断
- 用 `for` 和 `while` 让程序重复做事
- 用 `range()` 生成数字序列
- 写出一个完整的猜数字游戏

## 1. if 条件判断

程序需要「看情况办事」时，就用 `if`：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格，需要补考")
```

输出是 `及格`。注意三个关键点：

- 条件后面有冒号 `:`
- 条件成立时执行的代码要**缩进**（通常 4 个空格），缩进是 Python 语法的一部分
- `elif` 是 else if 的缩写，可以有多个；`else` 兜底，可以没有

条件里可以组合多个判断：`and`（并且）、`or`（或者）、`not`（取反）：

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以入场")
else:
    print("不能入场")
```

## 2. for 循环：重复固定的次数

```python
for i in range(5):
    print("第", i + 1, "次问好：你好！")
```

`range(5)` 产生 0、1、2、3、4 共五个数，循环体执行五次。
`range` 的三种用法：

```python
print(list(range(4)))       # [0, 1, 2, 3]：从 0 到 3
print(list(range(2, 6)))    # [2, 3, 4, 5]：从 2 到 5
print(list(range(0, 10, 3)))  # [0, 3, 6, 9]：步长为 3
```

规律：`range(起, 止, 步长)` 包含起点、**不包含终点**。

for 循环最常见的用途是累加、遍历：

```python
total = 0
for n in range(1, 101):
    total = total + n

print("1 加到 100 等于", total)   # 5050
```

## 3. while 循环：重复到条件不成立

不知道要循环多少次时用 `while`，条件为真就一直执行：

```python
countdown = 3

while countdown > 0:
    print("倒计时", countdown)
    countdown = countdown - 1   # 这行千万不能少

print("发射！")
```

`countdown = countdown - 1` 让数值每轮减小，最终条件 `countdown > 0`
变为假，循环结束。**忘了这一步，程序就会永远循环下去**（死循环），
只能按 Ctrl+C 强行停止。

## 4. break 与 continue

- `break`：立刻跳出整个循环
- `continue`：跳过本轮，继续下一轮

```python
for n in range(1, 10):
    if n == 3:
        continue        # 跳过 3
    if n == 7:
        break           # 到 7 就停，后面的不再执行
    print(n)
```

输出是 1、2、4、5、6（每行一个）。

## 5. 实战：猜数字游戏

把本课内容拼起来，做一个真能玩的游戏。`random` 是 Python 自带的随机数模块，
`input()` 让程序停下来等你从键盘输入：

```python
import random

answer = random.randint(1, 100)   # 随机生成 1~100 的答案
tries = 0

while True:
    guess = int(input("猜一个 1~100 的数字："))
    tries = tries + 1

    if guess > answer:
        print("太大了")
    elif guess < answer:
        print("太小了")
    else:
        print("猜对了！你一共猜了", tries, "次")
        break
```

自己玩两局，感受一下 `while True` + `break` 这个最常用的组合：
循环先无条件转起来，在「猜对」这个出口处用 `break` 跳出。

## 常见坑

1. **缩进不一致**：同一层级的代码缩进必须对齐，混用空格和 Tab 会报
   `IndentationError`。编辑器一般会把 Tab 自动转成 4 个空格。
2. **条件后面忘写冒号**：`if score >= 60` 后面少了 `:` 是新手最常见的报错。
3. **在循环里改错变量**：`while` 循环里更新的是另一个变量，
   条件永远为真，就会死循环。
4. **`input()` 得到的是字符串**：`int(input(...))` 先转成整数再比较，
   直接拿字符串和数字比大小会报错。
