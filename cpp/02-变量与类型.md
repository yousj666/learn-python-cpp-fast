# C++ 第 02 课：变量与类型

## 本课目标

- 理解 C++ 是强类型语言：变量必须先声明类型
- 掌握 int、double、char、bool、std::string 五种常用类型
- 学会类型转换和用 `std::cin` 读取输入

## 1. 声明变量：类型 + 名字

和 Python 不同，C++ 的变量在出生时就要定好类型，且一辈子不能变：

```cpp
#include <iostream>
#include <string>

int main() {
    int score = 95;            // 整数
    double price = 19.9;       // 小数
    char grade = 'A';          // 单个字符，用单引号
    bool is_open = true;       // 布尔值：true / false
    std::string name = "小明";  // 字符串，用双引号，需要 #include <string>

    std::cout << name << " 的分数是 " << score << std::endl;
    std::cout << "价格 " << price << "，等级 " << grade << std::endl;
    std::cout << "营业中吗？ " << is_open << std::endl;  // bool 输出为 1 或 0
    return 0;
}
```

`char` 和字符串别搞混：`'A'`（单引号）是一个字符，`"A"`（双引号）是字符串。

变量声明后可以改值，但不能改类型：

```cpp
#include <iostream>

int main() {
    int count = 10;
    count = 20;        // 没问题：还是 int
    // count = "二十";  // 编译错误：不能把字符串塞给 int
    std::cout << count << std::endl;
    return 0;
}
```

## 2. 整数和小数的运算

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 3;

    std::cout << a + b << std::endl;   // 13
    std::cout << a - b << std::endl;   // 7
    std::cout << a * b << std::endl;   // 30
    std::cout << a / b << std::endl;   // 3！两个整数相除，结果还是整数
    std::cout << a % b << std::endl;   // 1，取余

    double x = 10.0;
    std::cout << x / b << std::endl;   // 3.33333，只要有一方是小数就按小数算
    return 0;
}
```

**整数除法会直接丢掉小数部分**，这是 C++ 新手第一大坑：
想要小数结果，参与运算的数里至少要有一个是 `double`。

## 3. 类型转换

```cpp
#include <iostream>

int main() {
    double pi = 3.14;
    int truncated = (int)pi;              // 强制转换：3，小数部分被截断
    std::cout << truncated << std::endl;

    int n = 7;
    double widened = n;                   // int 自动变 double：7.0，没问题
    std::cout << widened << std::endl;

    char letter = 'A';
    std::cout << (int)letter << std::endl;  // 65：字符背后是 ASCII 编码数字
    return 0;
}
```

规则：小范围类型自动转成大范围（int → double 安全）；
反过来（double → int）会丢数据，需要写强制转换明确表示「我知道，我故意的」。

常量用 `const` 声明，声明后不能改，改了编译不过——这是好事，能防手误：

```cpp
#include <iostream>

int main() {
    const double TAX_RATE = 0.06;
    double price = 100.0;
    std::cout << "含税价：" << price * (1 + TAX_RATE) << std::endl;
    return 0;
}
```

## 4. 用 cin 读取输入

`std::cin` 和 `cout` 方向相反，把用户在键盘输入的内容读进变量：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "请输入你的名字：";
    std::cin >> name;
    std::cout << "请输入你的年龄：";
    std::cin >> age;

    std::cout << name << " 明年 " << age + 1 << " 岁" << std::endl;
    return 0;
}
```

运行后输入「小明」和「16」，输出 `小明 明年 17 岁`。
注意：`cin >> name` 读到空格就停，所以名字里别带空格；
要读一整行用 `std::getline(std::cin, name)`（第 05 课会再讲）。

## 常见坑

1. **整数除法**：`10 / 3` 是 3 不是 3.33，需要小数时写 `10.0 / 3`。
2. **变量未初始化就用**：`int x; std::cout << x;` 里 x 是随机垃圾值。
   声明时就给初值，养成习惯。
3. **char 用了双引号**：`char c = "A";` 会编译报错，单字符必须单引号。
4. **溢出**：int 有上限（约 21 亿），`int big = 3000000000;` 会溢出变成负数；
   大数字用 `long long`。

## 练习

1. 声明变量保存一本书的书名（string）、价格（double）、库存（int），
   全部打印出来。
2. 输入圆的半径（double），计算并输出圆的面积（π 取 3.14159，面积 = π × r × r）。
3. 输入一个摄氏温度（double），输出对应的华氏温度
   （公式：F = C * 9.0 / 5.0 + 32；想一想：这里为什么要用 9.0 而不是 9？）。

<details>
<summary>练习参考答案</summary>

```cpp
// 练习 1
#include <iostream>
#include <string>

int main() {
    std::string book_name = "C++ 编程入门";
    double book_price = 59.5;
    int book_stock = 120;

    std::cout << book_name << " 价格 " << book_price
              << " 库存 " << book_stock << std::endl;
    return 0;
}
```

```cpp
// 练习 2
#include <iostream>

int main() {
    const double PI = 3.14159;
    double r;
    std::cout << "输入半径：";
    std::cin >> r;
    std::cout << "面积是 " << PI * r * r << std::endl;
    return 0;
}
```

```cpp
// 练习 3
#include <iostream>

int main() {
    double c;
    std::cout << "输入摄氏温度：";
    std::cin >> c;
    double f = c * 9.0 / 5.0 + 32;
    std::cout << "华氏温度是 " << f << std::endl;
    return 0;
}
```

用 9.0 的原因：如果写 `c * 9 / 5`，`9 / 5` 这一步……其实 c 是 double，
整个表达式会按 double 计算，结果也对；但若温度变量是 int，
`9 / 5` 会先按整数除法得到 1，结果全错。用小数常量是最稳妥的写法。

</details>
