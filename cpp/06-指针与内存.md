# C++ 第 06 课：指针与内存

## 本课目标

- 理解内存地址和指针是什么
- 学会用 `&` 取地址、`*` 解引用
- 知道 `new` / `delete` 怎么回事，以及为什么现代 C++ 要少用它们

## 1. 变量住在内存里，每个都有地址

把内存想象成一排储物柜，每个柜子有编号（地址）。
变量就是占了一个柜子，平时我们用变量名存取东西；
而**指针**是一种特殊的变量，它存的不是数据本身，而是**另一个变量的地址**。

```cpp
#include <iostream>

int main() {
    int value = 42;

    std::cout << "值是 " << value << std::endl;
    std::cout << "地址是 " << &value << std::endl;   // & 取地址，输出形如 0x7ffc...
    return 0;
}
```

地址每次运行可能不同，这很正常——系统每次给程序分的柜子不一样。

## 2. 指针的基本操作

```cpp
#include <iostream>

int main() {
    int value = 42;
    int *p = &value;          // p 是指向 int 的指针，存着 value 的地址

    std::cout << "p 存的地址：" << p << std::endl;
    std::cout << "顺着地址找到的值：" << *p << std::endl;   // * 解引用：42

    *p = 100;                 // 通过指针修改原变量
    std::cout << "value 现在是 " << value << std::endl;      // 100
    return 0;
}
```

两个符号分清楚：

- 声明时的 `int *p`：星号是类型的一部分，读作「指向 int 的指针」
- 使用时的 `*p`：解引用，「顺着地址去取/改那个值」

指针和引用的区别（第 04 课学过引用）：引用是变量的「别名」，绑定后不能改绑；
指针是「地址牌」，可以换指向、可以为空。函数参数优先用引用，
需要「可能没有目标」或操作数组底层时才用指针。

## 3. 指针与数组

数组名在很多场合就是指向第一个元素的指针，这也是指针最实际的用途之一：

```cpp
#include <iostream>

int main() {
    int nums[4] = {10, 20, 30, 40};
    int *p = nums;            // 指向 nums[0]

    std::cout << *p << std::endl;        // 10
    std::cout << *(p + 1) << std::endl;  // 20：地址 +1 就是下一个元素
    std::cout << *(p + 3) << std::endl;  // 40

    // 用指针遍历数组（老式但经典的写法，理解即可，日常用下标或范围 for）
    for (int *q = nums; q < nums + 4; q++) {
        std::cout << *q << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

指针加 1 不是地址数字加 1，而是「跳到下一个元素」——
编译器按元素大小自动算步长，这叫指针算术。

## 4. 动态内存：new 和 delete

前面定义的变量，大小在编译时就定死了。有时需要运行时才决定要多大的空间，
就向系统「借」内存（堆内存）：

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "要存几个整数？";
    std::cin >> n;

    int *arr = new int[n];        // 运行时按 n 借空间
    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * 10;
    }
    for (int i = 0; i < n; i++) {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;

    delete[] arr;                 // 用完必须还！数组用 delete[]
    arr = nullptr;                // 还完把指针置空，防止误用
    return 0;
}
```

借了不还叫**内存泄漏**：程序越跑占得越多，最后拖垮系统。
借数组用 `new int[n]`，还的时候必须配对用 `delete[]`；
借单个用 `new int`，配对 `delete`。配错了是未定义行为。

**现代 C++ 的建议**：日常写代码优先用 `std::vector` 和智能指针
（`std::unique_ptr` 等），它们会自动还内存。裸 `new/delete` 要理解原理，
但新项目里能不用就不用：

```cpp
#include <iostream>
#include <vector>

int main() {
    int n = 5;
    std::vector<int> arr(n);      // 同样是运行时定大小，但不用手动 delete
    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * 10;
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;       // arr 离开作用域自动释放
    return 0;
}
```

## 5. 空指针

指针可以不指向任何东西，写成 `nullptr`。解引用空指针会直接崩溃，
所以用指针前先判断：

```cpp
#include <iostream>

int main() {
    int *p = nullptr;

    if (p != nullptr) {
        std::cout << *p << std::endl;
    } else {
        std::cout << "指针是空的，不能解引用" << std::endl;
    }
    return 0;
}
```

## 常见坑

1. **解引用未初始化的指针**：`int *p; *p = 5;` 中 p 指向随机地址，
   写过去轻则崩溃重则破坏数据。指针声明时就初始化（地址或 nullptr）。
2. **delete 之后继续用**：已释放的内存再读写是未定义行为，
   释放后立刻把指针设为 `nullptr`。
3. **new 和 delete 不配对**：`new[]` 配 `delete[]`，`new` 配 `delete`，
   混用是未定义行为。
4. **内存泄漏**：循环里反复 new 又不 delete 是最常见的泄漏来源；
   优先用 vector / 智能指针从根上避免。

## 练习

1. 定义变量 `double price = 9.9`，用指针把它的值改成 19.9，
   分别通过原变量和指针各打印一次验证。
2. 写函数 `void double_each(int *arr, int size)`，把数组每个元素翻倍，
   在 main 里用 `{1, 2, 3, 4}` 测试。
3. 用 `new` 动态创建存 3 个 double 的数组，赋值 1.5、2.5、3.5，
   求和打印，最后正确释放。

```cpp
// 练习 1
#include <iostream>

int main() {
    double price = 9.9;
    double *p = &price;

    *p = 19.9;

    std::cout << "原变量：" << price << std::endl;
    std::cout << "指针看到的：" << *p << std::endl;

}
```

```cpp
// 练习 2
#include <iostream>

void double_each(int *arr, int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;
    }
}

int main() {
    int nums[4] = {1, 2, 3, 4};
    double_each(nums, 4);
    for (int i = 0; i < 4; i++) {
        std::cout << nums[i] << " ";
    }
    std::cout << std::endl;   // 2 4 6 8
    return 0;
}
```

```cpp
// 练习 3
#include <iostream>

int main() {
    double *arr = new double[3];
    arr[0] = 1.5;
    arr[1] = 2.5;
    arr[2] = 3.5;

    double sum = arr[0] + arr[1] + arr[2];
    std::cout << "总和 " << sum << std::endl;   // 7.5

    delete[] arr;
    arr = nullptr;
    return 0;
}
```
