# C++ 第 01 课：环境与第一个程序

## 本课目标

- 准备好 C++ 编译器（g++ 或 clang++）
- 理解 C++ 程序要先「编译」再「运行」，和 Python 直接运行的区别
- 写出第一个 C++ 程序，学会用 `std::cout` 输出

## 1. C++ 和 Python 最大的不同：先编译

Python 是把代码交给解释器逐行执行的；C++ 则要先用**编译器**
把源代码一次性翻译成机器能直接执行的程序文件，然后再运行它：

```
源代码 hello.cpp  --编译-->  可执行文件 hello  --运行-->  输出结果
```

好处是运行速度极快（游戏、操作系统都靠它）；代价是每次改完代码都要重新编译。

## 2. 准备编译器

- **Windows**：安装 MinGW-w64 或 Visual Studio（勾选「使用 C++ 的桌面开发」）。
- **macOS**：终端运行 `xcode-select --install`，得到 clang++。
- **Linux**：`sudo apt install g++`（Debian/Ubuntu）。

验证安装：

```bash
g++ --version
```

能看到版本号（如 `g++ 13.x`）即可。macOS 上把命令里的 `g++` 换成 `clang++`，
用法完全一样。

## 3. 第一个程序

新建文件 `hello.cpp`，写入：

```cpp
#include <iostream>

int main() {
    std::cout << "你好，世界！" << std::endl;
    return 0;
}
```

编译并运行：

```bash
g++ -std=c++17 -Wall -o hello hello.cpp
./hello
```

输出：

```
你好，世界！
```

编译命令拆解：

- `g++`：编译器名字
- `-std=c++17`：使用 C++17 标准（本教程统一用它）
- `-Wall`：打开常见警告，强烈建议每次都带上，它能提前抓出很多错误
- `-o hello`：生成的可执行文件叫 `hello`（Windows 上会自动变 `hello.exe`）
- 最后是源文件名

逐行看代码：

- `#include <iostream>`：引入输入输出库，没有它就不能用 `cout`
- `int main() { ... }`：主函数，程序从这里开始执行，**每个 C++ 程序有且只有一个**
- `std::cout << "..."`：把内容「流向」标准输出；`std::endl` 表示换行
- `return 0;`：告诉操作系统「程序正常结束」

## 4. 多输出几行

```cpp
#include <iostream>

int main() {
    std::cout << "我正在学 C++" << std::endl;
    std::cout << "今年是 " << 2026 << " 年" << std::endl;
    std::cout << 3 + 4 << std::endl;
    return 0;
}
```

输出：

```
我正在学 C++
今年是 2026 年
7
```

`<<` 可以像链条一样连着用，把文字和数字拼在一行输出。
注意 `3 + 4` 会先算出 7 再输出；写成 `"3 + 4"`（带引号）则原样输出这串字符。

## 5. 注释

```cpp
#include <iostream>

int main() {
    // 这是单行注释：解释这一句在做什么
    std::cout << "注释不会被编译" << std::endl;

    /* 这是多行注释
       可以跨好几行 */
    std::cout << "程序继续运行" << std::endl;
    return 0;
}
```

## 常见坑

1. **忘了分号**：C++ 每条语句以 `;` 结尾，漏写是最常见的编译错误，
   报错行号经常指向下一行，别被带偏。
2. **改完代码没重新编译**：运行的还是旧的可执行文件，会让人以为改动没生效。
   改代码 → 编译 → 运行，三步不能省。
3. **中文标点**：代码里的引号、括号、分号必须是英文半角。
4. **main 函数的返回值**：写的是 `int main()`，就要有 `return 0;`。

## 练习

1. 把第一个程序的输出改成你的名字和一句「我开始学 C++ 了」，编译运行。
2. 写程序输出三行：你的城市、今年的年份、以及 `100 + 23` 的计算结果。
3. 故意删掉某行末尾的分号再编译，看报错信息长什么样，学会认它。
