# C++ 第 08 课：实战项目——命令行通讯录

## 本课目标

把前七课的知识全部用上，做一个真能用的**命令行通讯录**：

- 添加联系人（姓名 + 电话）
- 查看全部联系人
- 按姓名查找、删除联系人
- 数据保存在文件里，关掉程序不丢失

用到的知识：第 02 课的类型、第 03 课的循环判断、第 04 课的函数、
第 05 课的 vector 与 string、第 07 课的类。

## 1. 设计思路

- 一个联系人是一个 `Contact` 对象（姓名、电话两个成员）
- 通讯录是一个 `AddressBook` 类，内部用 `vector<Contact>` 保存所有人，
  负责添加、查找、删除和文件读写
- 文件格式用最朴素的文本：一行一个联系人，`姓名,电话`
  （和 Python 线第 06 课记分板用的格式一样，便于理解）
- 主函数是一个菜单循环：显示菜单 → 读选择 → 执行 → 回到菜单

## 2. 完整代码

把下面代码完整存为 `address_book.cpp`：

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <fstream>

class Contact {
public:
    std::string name;
    std::string phone;

    Contact(std::string n, std::string p) : name(n), phone(p) {}
};

class AddressBook {
private:
    std::vector<Contact> contacts;
    std::string filename;

public:
    AddressBook(std::string file) : filename(file) {
        load();
    }

    void load() {
        std::ifstream in(filename);
        if (!in) {
            return;   // 文件还不存在，当作空通讯录
        }
        std::string line;
        while (std::getline(in, line)) {
            size_t pos = line.find(",");
            if (pos == std::string::npos) {
                continue;   // 格式不对的行跳过
            }
            std::string name = line.substr(0, pos);
            std::string phone = line.substr(pos + 1);
            contacts.push_back(Contact(name, phone));
        }
    }

    void save() {
        std::ofstream out(filename);
        for (const Contact &c : contacts) {
            out << c.name << "," << c.phone << "\n";
        }
    }

    void add(const std::string &name, const std::string &phone) {
        contacts.push_back(Contact(name, phone));
        save();
        std::cout << "已添加：" << name << std::endl;
    }

    void list_all() {
        if (contacts.empty()) {
            std::cout << "通讯录是空的" << std::endl;
            return;
        }
        for (size_t i = 0; i < contacts.size(); i++) {
            std::cout << i + 1 << ". " << contacts[i].name
                      << " - " << contacts[i].phone << std::endl;
        }
    }

    void search(const std::string &keyword) {
        bool found = false;
        for (const Contact &c : contacts) {
            if (c.name.find(keyword) != std::string::npos) {
                std::cout << c.name << " - " << c.phone << std::endl;
                found = true;
            }
        }
        if (!found) {
            std::cout << "没有找到匹配的联系人" << std::endl;
        }
    }

    void remove_by_name(const std::string &name) {
        for (size_t i = 0; i < contacts.size(); i++) {
            if (contacts[i].name == name) {
                contacts.erase(contacts.begin() + i);
                save();
                std::cout << "已删除：" << name << std::endl;
                return;
            }
        }
        std::cout << "没有这个联系人" << std::endl;
    }
};

void print_menu() {
    std::cout << "\n===== 通讯录 =====" << std::endl;
    std::cout << "1. 添加联系人" << std::endl;
    std::cout << "2. 查看全部" << std::endl;
    std::cout << "3. 查找联系人" << std::endl;
    std::cout << "4. 删除联系人" << std::endl;
    std::cout << "0. 退出" << std::endl;
    std::cout << "请选择：";
}

int main() {
    AddressBook book("contacts.txt");

    while (true) {
        print_menu();
        int choice;
        if (!(std::cin >> choice)) {
            std::cout << "输入无效，程序结束" << std::endl;
            return 0;
        }
        std::cin.ignore();   // 吃掉选择数字后面的换行，方便后面 getline

        if (choice == 1) {
            std::string name, phone;
            std::cout << "姓名：";
            std::getline(std::cin, name);
            std::cout << "电话：";
            std::getline(std::cin, phone);
            book.add(name, phone);
        } else if (choice == 2) {
            book.list_all();
        } else if (choice == 3) {
            std::string keyword;
            std::cout << "输入要查找的姓名（可输入一部分）：";
            std::getline(std::cin, keyword);
            book.search(keyword);
        } else if (choice == 4) {
            std::string name;
            std::cout << "输入要删除的姓名：";
            std::getline(std::cin, name);
            book.remove_by_name(name);
        } else if (choice == 0) {
            std::cout << "再见！" << std::endl;
            break;
        } else {
            std::cout << "没有这个选项" << std::endl;
        }
    }
    return 0;
}
```

编译运行：

```bash
g++ -std=c++17 -Wall -o address_book address_book.cpp
./address_book
```

## 3. 运行演示

依次输入（每行是你要敲的内容）：

```
1
小明
13800000001
1
小红
13800000002
2
3
小
4
小明
2
0
```

你会看到：添加成功两次 → 列表显示两人 → 查找「小」把两人都列出来
（因为是子串匹配）→ 删除小明 → 再看列表只剩小红 → 退出。
退出后重新运行选 2，小红还在——数据保存在同目录的 `contacts.txt` 里，
内容长这样：

```
小红,13800000002
```

## 4. 代码里值得注意的设计

1. **文件操作用 `<fstream>`**：`std::ifstream` 读、`std::ofstream` 写，
   用法像 `cin`/`cout`；对象离开作用域自动关闭文件（RAII，第 07 课）。
2. **每次改动立刻 save()**：添加、删除后马上写文件，
   程序意外退出也不丢已保存的数据。
3. **`const Contact &c` 遍历**：引用避免复制每个对象，
   `const` 保证只读（第 04 课的引用在这里真正派上用场）。
4. **`cin >> choice` 后要 `ignore()`**：数字读完后换行符还留在缓冲区，
   不吃掉它，下一个 `getline` 会读到空行（第 05 课的常见坑）。

## 常见坑

1. **姓名里别带逗号**：数据格式用逗号分隔，姓名或电话里出现逗号会把
   一行拆错。真实项目会用更稳妥的格式（如 JSON），本课先用最朴素的方案。
2. **在别的目录运行**：`contacts.txt` 生成在运行目录，换目录运行就是
   另一份通讯录了。
3. **erase 时迭代器失效**：`remove_by_name` 删完立刻 `return` 是故意的，
   在循环里 erase 后继续用旧下标/迭代器是经典错误来源。
