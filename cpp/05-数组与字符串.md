# C++ 第 05 课：数组与字符串

## 本课目标

- 用数组保存一组同类型数据
- 用 `std::vector`——更现代、更安全的「动态数组」
- 掌握 `std::string` 的常用操作

## 1. 数组：固定长度的队伍

数组把一组**同类型**的数据排在一起，下标从 0 开始：

```cpp
#include <iostream>

int main() {
    int scores[5] = {88, 95, 72, 100, 66};

    std::cout << scores[0] << std::endl;   // 88
    std::cout << scores[4] << std::endl;   // 66

    scores[2] = 80;                        // 修改下标 2 的元素

    int total = 0;
    for (int i = 0; i < 5; i++) {
        total += scores[i];
    }
    std::cout << "平均分 " << total / 5.0 << std::endl;
    return 0;
}
```

数组的长度在定义时就定死了，写代码时要自己记住长度（这里是 5）。
**访问越界下标（如 `scores[5]`）不会报错，而是读到垃圾值甚至让程序崩溃**，
C++ 不会像 Python 那样拦你——这是效率换来的代价，要格外小心。

## 2. vector：会自己长大的数组

实际开发里更常用 `std::vector`：长度可变、自带 `size()`、越界时用
`.at()` 还能帮你检查：

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> nums = {5, 2, 9, 1, 7};

    nums.push_back(4);                    // 末尾添加，长度自动变 6
    std::cout << "长度 " << nums.size() << std::endl;

    int total = 0;
    for (int n : nums) {                  // 范围 for：依次取出每个元素
        total += n;
    }
    std::cout << "总和 " << total << std::endl;

    std::cout << "第一个 " << nums.front()
              << "，最后一个 " << nums.back() << std::endl;
    return 0;
}
```

范围 for（`for (int n : nums)`）是 C++11 起的写法，遍历容器时比下标循环简洁得多。

排序用标准库的 `std::sort`（在 `<algorithm>` 里）：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> nums = {5, 2, 9, 1, 7};

    std::sort(nums.begin(), nums.end());   // 从小到大

    for (int n : nums) {
        std::cout << n << " ";
    }
    std::cout << std::endl;   // 1 2 5 7 9
    return 0;
}
```

## 3. string 字符串

`std::string` 是 C++ 的字符串类型，能直接拼接、比较、求长度：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string first = "Py";
    std::string second = "thon";
    std::string word = first + second;      // 拼接

    std::cout << word << std::endl;                 // Python
    std::cout << "长度 " << word.size() << std::endl;  // 6
    std::cout << word[0] << word[5] << std::endl;      // P n

    std::cout << word.substr(0, 3) << std::endl;    // Pyt：从下标 0 取 3 个字符

    if (word == "Python") {                          // 字符串可以直接比较
        std::cout << "比较成功" << std::endl;
    }
    return 0;
}
```

查找子串用 `find`，找不到时返回 `std::string::npos`：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string text = "I love C++ programming";

    size_t pos = text.find("C++");
    if (pos != std::string::npos) {
        std::cout << "在下标 " << pos << " 处找到 C++" << std::endl;
    } else {
        std::cout << "没找到" << std::endl;
    }
    return 0;
}
```

## 4. 读一整行输入

`cin >> s` 遇到空格就停。读整行（含空格）用 `std::getline`：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string line;
    std::cout << "输入一句话：";
    std::getline(std::cin, line);
    std::cout << "你输入了 " << line.size() << " 个字符" << std::endl;
    return 0;
}
```

## 常见坑

1. **数组越界不报错**：下标写错程序可能照常运行但结果全错，
   这是 C++ 最难查的 bug 类型之一。能用 vector 就用 vector。
2. **`size()` 的返回值是无符号数**：拿它和负数比较会有奇怪结果，
   循环里写 `for (int i = 0; i < (int)nums.size(); i++)` 或用范围 for 更稳。
3. **混用 cin 和 getline**：`cin >> age` 后紧接着 `getline` 会读到一个空行
   （残留的换行符被它当成一整行）。中间加一句 `std::cin.ignore();` 吃掉换行。
4. **字符串下标越界**：`word[word.size()]` 是未定义行为，别碰；
   合法下标是 0 到 size()-1。

## 练习

1. 用 vector 存 `[72, 85, 90, 66, 95, 58, 88]`，统计及格人数、
   最高分和平均分。
2. 输入一句话（用 getline），统计里面空格的个数并输出单词数（空格数 + 1，
   假设没有连续空格）。
3. 把字符串 `"2026-11-27"` 按 `-` 拆成年、月、日三部分并分别打印
   （提示：用 `find("-")` 找位置，`substr` 切片，分两步找第二个 `-`）。

```cpp
// 练习 1
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {72, 85, 90, 66, 95, 58, 88};

    int passed = 0;
    int best = scores[0];
    int total = 0;
    for (int s : scores) {
        if (s >= 60) passed++;
        if (s > best) best = s;
        total += s;
    }

    std::cout << "及格人数 " << passed << std::endl;
    std::cout << "最高分 " << best << std::endl;
    std::cout << "平均分 " << total / (double)scores.size() << std::endl;
    return 0;
}
```

```cpp
// 练习 2
#include <iostream>
#include <string>

int main() {
    std::string line;
    std::cout << "输入一句话：";
    std::getline(std::cin, line);

    int spaces = 0;
    for (char c : line) {
        if (c == ' ') spaces++;
    }

    std::cout << "空格数 " << spaces << "，单词数 " << spaces + 1 << std::endl;
    return 0;
}
```

```cpp
// 练习 3
#include <iostream>
#include <string>

int main() {
    std::string date = "2026-11-27";

    size_t first = date.find("-");
    size_t second = date.find("-", first + 1);

    std::string year = date.substr(0, first);
    std::string month = date.substr(first + 1, second - first - 1);
    std::string day = date.substr(second + 1);

    std::cout << "年：" << year << " 月：" << month << " 日：" << day << std::endl;
    return 0;
}
```
