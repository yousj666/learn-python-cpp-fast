# C++ 第 03 课：条件与循环

## 本课目标

- 用 `if / else if / else` 和 `switch` 做判断
- 用 `for` 和 `while` 循环重复执行代码
- 写出一个完整的猜数字游戏

## 1. if 条件判断

```cpp
#include <iostream>

int main() {
    int score = 85;

    if (score >= 90) {
        std::cout << "优秀" << std::endl;
    } else if (score >= 60) {
        std::cout << "及格" << std::endl;
    } else {
        std::cout << "不及格，需要补考" << std::endl;
    }
    return 0;
}
```

和 Python 对照着记：条件要写在括号里、代码块用大括号 `{}` 包起来、
每句末尾有分号、没有冒号。

多个条件用逻辑运算符连接：`&&`（并且）、`||`（或者）、`!`（取反）：

```cpp
#include <iostream>

int main() {
    int age = 20;
    bool has_ticket = true;

    if (age >= 18 && has_ticket) {
        std::cout << "可以入场" << std::endl;
    } else {
        std::cout << "不能入场" << std::endl;
    }
    return 0;
}
```

## 2. switch：多路分支

判断同一个变量的多个取值时，`switch` 比一串 `else if` 更清爽：

```cpp
#include <iostream>

int main() {
    int day = 3;

    switch (day) {
        case 1: std::cout << "周一" << std::endl; break;
        case 2: std::cout << "周二" << std::endl; break;
        case 3: std::cout << "周三" << std::endl; break;
        default: std::cout << "其他日子" << std::endl; break;
    }
    return 0;
}
```

**每个 case 后面的 `break` 千万别漏**：漏了会继续往下执行后面 case 的代码
（叫 fallthrough），是经典 bug 来源。

## 3. for 循环

```cpp
#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << "第 " << i << " 次问好：你好！" << std::endl;
    }
    return 0;
}
```

括号里三段用分号隔开：**初始化** `int i = 1`（只执行一次）、
**条件** `i <= 5`（每轮开始前检查）、**更新** `i++`（每轮结束后执行，i 自增 1）。

经典用法：累加求和。

```cpp
#include <iostream>

int main() {
    int total = 0;
    for (int n = 1; n <= 100; n++) {
        total += n;    // 等价于 total = total + n
    }
    std::cout << "1 加到 100 等于 " << total << std::endl;  // 5050
    return 0;
}
```

## 4. while 循环

条件为真就一直执行，适合不知道循环次数的场景：

```cpp
#include <iostream>

int main() {
    int countdown = 3;

    while (countdown > 0) {
        std::cout << "倒计时 " << countdown << std::endl;
        countdown--;    // 等价于 countdown = countdown - 1，别忘了这一步
    }

    std::cout << "发射！" << std::endl;
    return 0;
}
```

还有一种 `do-while`：先执行一次，再检查条件，至少会跑一轮：

```cpp
#include <iostream>

int main() {
    int n = 10;
    do {
        std::cout << "至少执行一次，现在 n = " << n << std::endl;
    } while (n < 5);   // 条件是假的，但已经执行过一次了
    return 0;
}
```

`break` 立刻跳出循环，`continue` 跳过本轮剩余部分——和 Python 里一样：

```cpp
#include <iostream>

int main() {
    for (int n = 1; n < 10; n++) {
        if (n == 3) continue;   // 跳过 3
        if (n == 7) break;      // 到 7 停
        std::cout << n << std::endl;
    }
    return 0;
}
```

输出 1、2、4、5、6。

## 5. 实战：猜数字游戏

`rand()` 是 C 语言传下来的随机数函数，配 `srand(time(0))` 用当前时间做种子，
每次运行的随机序列才不一样：

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0));
    int answer = rand() % 100 + 1;   // 1~100
    int tries = 0;
    int guess;

    while (true) {
        std::cout << "猜一个 1~100 的数字：";
        std::cin >> guess;
        tries++;

        if (guess > answer) {
            std::cout << "太大了" << std::endl;
        } else if (guess < answer) {
            std::cout << "太小了" << std::endl;
        } else {
            std::cout << "猜对了！你一共猜了 " << tries << " 次" << std::endl;
            break;
        }
    }
    return 0;
}
```

## 常见坑

1. **if 条件里写成 `=`**：`if (score = 60)` 不是比较，是赋值，
   而且结果永远为真。比较相等一定是 `==`。开 `-Wall` 编译时它会警告你。
2. **switch 漏 break**：见上文，会一路执行下去。
3. **分号写在 if 后面**：`if (x > 0); { ... }` 中间的分号让 if 变成空语句，
   大括号里的代码会无条件执行。报错不报错，全靠细心。
4. **死循环**：while 里忘了更新条件变量，程序永远停不下来，
   终端里按 Ctrl+C 强制结束。

## 练习

1. 输入一个年份，判断是否为闰年（能被 400 整除，或能被 4 整除但不能被 100 整除）。
2. 用双重 for 循环打印 9×9 乘法表的前三行段（i 从 1 到 3，j 从 1 到 i）。
3. 用 while 循环计算：从 1 开始累加，最少加到几时总和第一次超过 1000？

<summary>练习参考答案</summary>

```cpp
// 练习 1
#include <iostream>

int main() {
    int year;
    std::cout << "输入年份：";
    std::cin >> year;

    if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
        std::cout << year << " 是闰年" << std::endl;
    } else {
        std::cout << year << " 不是闰年" << std::endl;
    }
    return 0;
}
```

```cpp
// 练习 2
#include <iostream>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= i; j++) {
            std::cout << j << "×" << i << "=" << i * j << "  ";
        }
        std::cout << std::endl;
    }
    return 0;
}
```

```cpp
// 练习 3
#include <iostream>

int main() {
    int total = 0;
    int n = 0;

    while (total <= 1000) {
        n++;
        total += n;
    }

    std::cout << "加到 " << n << " 时总和第一次超过 1000，总和是 "
              << total << std::endl;
    return 0;
}
```
