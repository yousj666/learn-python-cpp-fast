# C++ 第 07 课：类与对象

## 本课目标

- 定义类：把数据（成员变量）和操作（成员函数）打包
- 理解封装：`public` 和 `private`
- 学会构造函数、析构函数和继承

## 1. 第一个类

类是「图纸」，对象是按图纸造出的实例。和 Python 的 class 思想相同，
C++ 多了类型声明和访问控制：

```cpp
#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int score;

    void introduce() {
        std::cout << "我是 " << name << "，这次考了 " << score << " 分" << std::endl;
    }

    bool is_passed() {
        return score >= 60;
    }
};

int main() {
    Student ming;             // 造对象
    ming.name = "小明";
    ming.score = 95;
    ming.introduce();
    std::cout << "及格了吗？ " << ming.is_passed() << std::endl;
    return 0;
}
```

注意类定义结尾的大括号后面有**分号**，这是 C++ 类定义最容易漏的东西。

## 2. 构造函数：出生时就把数据装好

像上面那样造完对象再逐个赋值很啰嗦。用**构造函数**在创建时一步到位：
构造函数与类同名、没有返回值：

```cpp
#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int score;

    Student(std::string n, int s) {   // 构造函数
        name = n;
        score = s;
    }

    void introduce() {
        std::cout << "我是 " << name << "，这次考了 " << score << " 分" << std::endl;
    }
};

int main() {
    Student ming("小明", 95);   // 创建时直接传初始值
    Student hong("小红", 88);
    ming.introduce();
    hong.introduce();
    return 0;
}
```

更地道的写法是**成员初始化列表**，效率更好，也是老手默认的写法：

```cpp
#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int score;

    Student(std::string n, int s) : name(n), score(s) {
        // 冒号后面就是初始化列表，函数体可以为空
    }

    void introduce() {
        std::cout << "我是 " << name << "，这次考了 " << score << " 分" << std::endl;
    }
};

int main() {
    Student ming("小明", 95);
    ming.introduce();
    return 0;
}
```

## 3. 封装：private 保护数据

把成员变量设为 `private`，外部就不能乱改，只能通过类提供的方法操作——
规则写在类里，处处生效（和 Python 第 07 课银行账户的思想一样）：

```cpp
#include <iostream>
#include <string>

class BankAccount {
private:
    std::string owner;
    int balance;              // 私有：外面碰不到

public:
    BankAccount(std::string o) : owner(o), balance(0) {}

    void deposit(int amount) {
        if (amount > 0) {
            balance += amount;
            std::cout << "存入 " << amount << "，余额 " << balance << std::endl;
        }
    }

    void withdraw(int amount) {
        if (amount > balance) {
            std::cout << "余额不足，取款失败" << std::endl;
        } else {
            balance -= amount;
            std::cout << "取出 " << amount << "，余额 " << balance << std::endl;
        }
    }

    int get_balance() {       // 只读查看余额的正规通道
        return balance;
    }
};

int main() {
    BankAccount account("小明");
    account.deposit(500);
    account.withdraw(120);
    account.withdraw(1000);
    // account.balance = 1000000;   // 编译错误：balance 是私有的，改不了
    std::cout << "最终余额 " << account.get_balance() << std::endl;
    return 0;
}
```

- `public`：外部可以访问（方法通常放这里）
- `private`：只有类自己的方法能访问（数据通常放这里），不写默认就是 private

## 4. 析构函数：对象销毁时自动收尾

对象离开作用域时，**析构函数**（类名前加 `~`）自动执行，
常用来释放第 06 课的动态内存：

```cpp
#include <iostream>

class Buffer {
private:
    int *data;

public:
    Buffer(int size) {
        data = new int[size];
        std::cout << "申请了内存" << std::endl;
    }

    ~Buffer() {               // 析构函数
        delete[] data;
        std::cout << "释放了内存" << std::endl;
    }
};

int main() {
    {
        Buffer buf(10);
        std::cout << "正在使用" << std::endl;
    }   // buf 在这里离开作用域，析构函数自动执行
    std::cout << "已经出了作用域" << std::endl;
    return 0;
}
```

输出顺序是：申请了内存 → 正在使用 → 释放了内存 → 已经出了作用域。
「谁申请谁释放、自动执行」这个模式叫 RAII，是 C++ 管理资源的核心思想，
vector、string 内部都是这么干的——这也是它们不用手动 delete 的原因。

## 5. 继承

子类继承父类的成员，再追加或改写：

```cpp
#include <iostream>
#include <string>

class Animal {
protected:
    std::string name;         // protected：自己和子类能访问，外界不行

public:
    Animal(std::string n) : name(n) {}

    virtual void speak() {    // virtual：允许子类重写
        std::cout << name << " 发出了声音" << std::endl;
    }
};

class Dog : public Animal {
public:
    Dog(std::string n) : Animal(n) {}   // 先调用父类构造函数

    void speak() override {             // 重写父类方法
        std::cout << name << "：汪汪！" << std::endl;
    }
};

class Cat : public Animal {
public:
    Cat(std::string n) : Animal(n) {}

    void speak() override {
        std::cout << name << "：喵喵~" << std::endl;
    }
};

int main() {
    Dog dog("旺财");
    Cat cat("咪咪");
    dog.speak();
    cat.speak();
    return 0;
}
```

和 Python 对照：C++ 的重写要父类方法带 `virtual`、子类方法带 `override`
（override 可省但建议写，写错方法名时编译器会报错帮你抓虫）。

## 常见坑

1. **类定义结尾漏分号**：`};` 的分号漏了，报错会指向后面的代码，极具迷惑性。
2. **忘了初始化成员**：没写构造函数时，int 成员是随机值。
   给成员写默认值（如 `int score = 0;`）或用构造函数初始化。
3. **在类外直接改 private 成员**：编译错误是封装在保护你，
   应该给类加正规的 public 方法。
4. **有指针成员却不写析构**：对象销毁时内存没释放就是泄漏；
   要么写析构 `delete`，要么干脆用 vector 代替裸指针。

// 练习 1
#include <iostream>

class Rectangle {
private:
    double width;
    double height;

public:
    Rectangle(double w, double h) : width(w), height(h) {}

    double area() {
        return width * height;
    }

    double perimeter() {
        return 2 * (width + height);
    }
};

int main() {
    Rectangle r1(3, 4);
    std::cout << r1.area() << " " << r1.perimeter() << std::endl;
    Rectangle r2(5, 6);

    return 0;
}
