# C++ 第 04 课：函数与引用

## 本课目标

- 学会定义和调用函数，理解返回值类型
- 掌握函数重载：同名函数，不同参数
- 理解引用参数：让函数能真正修改传进来的变量

## 1. 定义函数

C++ 的函数要在名字前写明**返回值类型**，每个参数也要写类型：

```cpp
#include <iostream>

int rectangle_area(int width, int height) {
    return width * height;
}

int main() {
    std::cout << rectangle_area(3, 4) << std::endl;    // 12
    std::cout << rectangle_area(5, 6) << std::endl;    // 30
    return 0;
}
```

不需要返回值的函数，返回类型写 `void`：

```cpp
#include <iostream>
#include <string>

void say_hello(std::string name) {
    std::cout << "你好，" << name << "！欢迎学习 C++" << std::endl;
    // 没有 return 也行，函数到大括号结束自动返回
}

int main() {
    say_hello("小明");
    say_hello("小红");
    return 0;
}
```

注意：函数要写在 `main` **之前**（或者先在前面写一行函数声明），
因为编译器是从上往下读的，`main` 里调用的函数必须先让它「见过」。

## 2. 默认参数

```cpp
#include <iostream>

int power(int base, int exp = 2) {   // exp 默认是 2
    int result = 1;
    for (int i = 0; i < exp; i++) {
        result *= base;
    }
    return result;
}

int main() {
    std::cout << power(5) << std::endl;       // 25，用了默认的平方
    std::cout << power(2, 10) << std::endl;   // 1024
    return 0;
}
```

和 Python 一样：带默认值的参数要放在后面。

## 3. 函数重载

C++ 允许几个函数同名，只要**参数列表不同**，编译器会按实参自动挑：

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    std::cout << add(1, 2) << std::endl;        // 3，走 int 版
    std::cout << add(1.5, 2.5) << std::endl;    // 4，走 double 版
    std::cout << add(1, 2, 3) << std::endl;     // 6，走三参数版
    return 0;
}
```

标准库里大量函数都是重载的，用起来像「一个名字干多种活」。

## 4. 引用：本课的重点

默认情况下，参数传进函数的是**副本**（值传递），函数里怎么改都不影响外面：

```cpp
#include <iostream>

void try_change(int x) {
    x = 99;
}

int main() {
    int value = 10;
    try_change(value);
    std::cout << value << std::endl;   // 还是 10，没被改掉
    return 0;
}
```

参数类型后加 `&` 变成**引用传递**，传进来的就是变量本人：

```cpp
#include <iostream>

void swap_values(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3;
    int y = 7;
    swap_values(x, y);
    std::cout << "x = " << x << ", y = " << y << std::endl;  // x = 7, y = 3
    return 0;
}
```

交换两个变量的值是引用最经典的用途——用副本是永远换不成的。

引用还有一个常见用法：参数是很大的对象时，用 `const 类型&` 传参，
既避免复制的开销，又保证函数里不会误改它（第 05、07 课会用到）。

## 5. 作用域

大括号 `{}` 圈出的范围就是作用域，里面定义的变量出了大括号就不存在：

```cpp
#include <iostream>

int g = 10;   // 全局变量，整个文件可见（能不用就不用，容易出乱子）

int main() {
    int local = 5;
    if (true) {
        int inner = 99;
        std::cout << inner << std::endl;   // 99，在自己的作用域里
    }
    // std::cout << inner << std::endl;   // 编译错误：inner 已经不存在了
    std::cout << local << " " << g << std::endl;
    return 0;
}
```

## 常见坑

1. **函数定义在 main 之后又没写声明**：编译器报「未声明就使用」。
   解决：把函数定义挪到 main 前，或在前面补一行声明 `int add(int, int);`。
2. **返回类型对不上**：声明返回 int 的函数里 `return 3.5;` 会被截断成 3，
   不报错但结果错。开 `-Wall` 能收到警告。
3. **以为值传递能改原变量**：改不动。想改就用引用 `&`。
4. **void 函数里写 return 带值**：`return 5;` 在 void 函数里是编译错误。

## 练习

1. 写函数 `bool is_even(int n)`，判断整数是否为偶数；用它打印 1~10 的所有偶数。
2. 写函数 `double celsius_to_fahrenheit(double c)` 完成温度转换，
   在 main 里打印 0、37、100 三个值。
3. 写函数 `void add_one(int &x)` 把参数加 1；在 main 里对同一个变量连调三次，
   打印最终结果验证引用真的改到了原变量。

<details>
<summary>练习参考答案</summary>

```cpp
// 练习 1
#include <iostream>

bool is_even(int n) {
    return n % 2 == 0;
}

int main() {
    for (int i = 1; i <= 10; i++) {
        if (is_even(i)) {
            std::cout << i << std::endl;
        }
    }
    return 0;
}
```

```cpp
// 练习 2
#include <iostream>

double celsius_to_fahrenheit(double c) {
    return c * 9.0 / 5.0 + 32;
}

int main() {
    double temps[3] = {0, 37, 100};
    for (int i = 0; i < 3; i++) {
        std::cout << temps[i] << "℃ = "
                  << celsius_to_fahrenheit(temps[i]) << "℉" << std::endl;
    }
    return 0;
}
```

```cpp
// 练习 3
#include <iostream>

void add_one(int &x) {
    x = x + 1;
}

int main() {
    int value = 10;
    add_one(value);
    add_one(value);
    add_one(value);
    std::cout << value << std::endl;   // 13
    return 0;
}
```
